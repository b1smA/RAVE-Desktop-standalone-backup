# Getting started

RAVE separates music metadata from audio playback. Installed plugins provide search results, artist and release information, streaming candidates, lyrics, discovery, and dashboard content.

## First launch

The main window contains navigation on the left, the active view in the center, the queue on the right, and playback controls at the bottom. Open **Settings → Plugins** to review installed providers and the plugin store.

RAVE needs these capabilities to play music:

- a metadata provider for search and release information;
- a streaming provider for playable audio.

A single plugin may provide both capabilities. Plugins activate after installation without restarting the application.

## Search and playback

1. Enter an artist, release, or track in the search field.
2. Open a result or use its context menu.
3. Select **Play now**, **Play next**, or **Add to queue**.
4. Open **Sources** when you want to inspect or change the active providers.

Smart Source evaluates available streaming candidates using title and duration matching, quality, response time, reliability, rejected-version feedback, and your provider preferences. The source inspector explains the selected candidate and provides diagnostics.

## Personalize RAVE

Useful next steps include:

- save tracks, releases, and artists to favorites;
- create playlists or use **Listen Later**;
- configure Smart Queue, automatic radio, sleep behavior, and recommendation filters;
- open the mini player from the player bar;
- enable local remote control or protected collaborative sessions;
- choose an audio output device from the volume control.

Review [RAVE features](rave-features.md) for the complete overview and [Known limitations](known-limitations.md) before relying on provider-dependent or platform-specific functionality.
